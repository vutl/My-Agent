# Sealed v4 corpus: notes for question authors and judges

20 files in `raw/` (12 English, 8 Vietnamese). Formats: 7 native PDFs, 3 scanned PDFs, 1 slide-deck PDF, 4 DOCX, 3 Markdown, 2 TXT.
Topics do not overlap v1-v3: no macro or central-bank documents, no ENSO/climate outlooks, labour, administrative-unit, education-statistics, energy-outlook, gravitational-wave, robot-policy, NLP/RAG, dengue or PEP documents. The library covers US agricultural outlook and bee-keeping bulletins, aviation-safety board documents, two computer-vision papers plus a project README, malaria and wheat articles in English and Vietnamese, and Vietnamese agriculture/food/health circulars.
`manifest.json` holds URLs, licenses, hashes, page counts and per-file verification. `build_scripts/` holds the pipeline: `fetch_all.sh` -> `build_corpus.sh` -> `make_manifest.py` (`sources.json` is the metadata input).
All page numbers below are 1-based PDF page indices, not printed page numbers.

## Things to know

- **Stamped numbers/dates (VN circulars)**: for TT 75, TT 28 and TT 27/BNNMT the number and date ("Số: 28/2026/TT-BNNMT, ngày 30 tháng 6 năm 2026") are image stamps. The text layer shows "Số: /2026/TT-BNNMT" with blanks, so the number is visible only when a page is rendered. VBHN 16 has a similar stamp (the text layer ends with the loose digits "16 09 12", presumably Số 16, ngày 09/12/2025). TT 27/BYT is fully scanned, so everything is only visual.
- **Quasi-drafts**: the tiêm chủng file is a real consultation draft ("DỰ THẢO 1", blank number, "Điều ..." placeholders). TT 75, 28 and 27/BNNMT are signed circulars; TT 75 and 28 leave the effective date blank in the text ("kể từ ngày tháng năm 2026").
- **Garbled text layer**: the BYT circular's native PDF text layer is corrupt (e.g. "T ÔN TƯ", missing capitals). That is why it was converted to an image-only scan; the reference answers were written from the rendered pages.
- **Scanned PDFs** were made by rasterizing the native originals with PyMuPDF (`scan_pdf.py`) and contain exactly the original content. They have no text layer: PyMuPDF and pypdf both return 0 characters and each page holds a single image. Sep WASDE 200 dpi colour, NTSB synopsis 200 dpi colour, TT 27/BYT 200 dpi grey.
- **Converted DOCX/MD** (Wikipedia) come from REST HTML at fixed revisions (see URLs). Navboxes, references and "see also" sections were dropped; figures appear only as captions.
- **TXT**: Project Gutenberg boilerplate (licence, transcriber notes) is part of the files and counts as text.
- **Verification** used PyMuPDF and pypdf (no poppler on this machine), python-docx for DOCX and UTF-8 decoding for MD/TXT. `manifest.json` has `all_verified: true` (TT 28 is allowed one blank page).
- Largest file: scanned Sep WASDE 12.3 MB; all files are < 40 MB; longest document is the 85-page BNNMT circular.
- **Not in the corpus**, so good targets for unanswerable questions: any WASDE other than Sep/Oct 2026 (and any 2027/28 projection), the NTSB final report AIR-25-04 or the January 2026 final report, FB 397, TT 08/2011/TT-BYT, QĐ 2879/QĐ-BYT, the annex product lists of TT 75/TT 28, any Vietnam-specific malaria or wheat statistics, ViT-G results, YOLOv10 FPS on any consumer GPU.
